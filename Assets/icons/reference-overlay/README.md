# Reference Overlay Icons

Use transparent PNG files.

## Required files

- `reference_mode_loop_24.png`
- `reference_mode_hold_24.png`

## Recommended size

- Base size: 24x24 px
- Optional HiDPI variant: 48x48 px (same filename pattern with `_48` suffix)

## Notes

- Keep icon design monochrome (white/light gray) for dark UI.
- Use 2 px visual padding inside the canvas to avoid clipping.
